# مصحف

تطبيق React Native وExpo عربي لقراءة القرآن. يجلب نص السور مباشرة من واجهة Quran.com العامة، لذلك لا تحتاج إلى إنشاء أو استضافة باك إند خاص بالتطبيق.

## التشغيل

```bash
npm install
npx expo start
```

لا يلزم إعداد مفاتيح أو ملف `.env` أو تشغيل خادم. يحتاج تحميل صفحة جديدة أو قائمة السور إلى الإنترنت. تُحفظ الصفحة وخطها الخاص محليًا بعد فتحها، ويمكن قراءتها لاحقًا دون اتصال؛ الصفحات غير المفتوحة والتلاوات لا تتوفر دون اتصال.

لإنشاء حزمة Android للتطوير:

```bash
npx expo run:android
```

## مصدر المحتوى

يستخدم التطبيق Quran.com API v4 لجلب أسماء السور والنص العثماني، ويتحقق من اكتمال الاستجابة وترتيب الآيات والكلمات قبل عرضها. راجع [تفاصيل التكامل](./docs/api-integrations.md) و[مصادر البيانات](./docs/data-sources.md).

إتاحة الواجهة العامة لا تعني تلقائيًا السماح بإعادة توزيع المحتوى أو استخدامه تجاريًا. شروط Quran.com المنشورة تقصر استخدام المحتوى على الاستخدام الشخصي غير التجاري؛ راجع [الترخيص](./docs/licensing.md) قبل نشر التطبيق.

# Licensing and Attribution

No Quran text, Tajweed, tafsir, audio, or page-layout dataset has been copied into this project.

Before a source is imported, cached offline, redistributed, or shown in production:

1. Review the current source license and terms for the exact content.
2. Verify commercial-use, offline-caching, and redistribution permissions separately.
3. Preserve required text, reciter, translator, and publisher attribution.
4. Record the canonical source, version, checksum, license, and required notices in `docs/data-sources.md`.
5. Obtain scholarly/content review for Quranic and Tajweed datasets where required.

Quran Foundation API availability is not by itself confirmation that every returned recording or referenced work can be redistributed or downloaded offline. Tanzil is only a potential text source; its current license and modification restrictions must be reviewed before use.

## Release gate

Do not ship bundled content or offline audio until the applicable license, attribution, and caching/redistribution rights have been verified and recorded.
